# 股票行情 (Stocks Ticker)

一个 VSCode 扩展，在命令面板查询**港股/美股**实时行情，配状态栏轮播与侧边栏自选股列表。

## 功能

- **命令面板查询**（`Cmd/Ctrl+Shift+P` → `股票行情: 查询`，或快捷键 `Cmd/Ctrl+Shift+S`）：
  输入港股代码（4-6位数字，如 `00700`）或美股代码（字母，如 `AAPL`），即时获取实时报价。
- **状态栏轮播**：在自选股之间轮播，显示现价 + 涨跌幅。
- **侧边栏自选股列表**（活动栏图标）：列出全部自选股及实时行情，行内按钮可移除。
- **自适应刷新**：交易时段 5 秒，非交易时段 30 秒（港股/美股时段）。

## 命令

| 命令 | 说明 |
| --- | --- |
| `股票行情: 查询` | Quick Pick 搜索 + 实时报价 |
| `股票行情: 添加到自选股` | 通过输入框添加代码 |
| `股票行情: 从自选股移除` | 通过 Quick Pick / 侧边栏按钮移除 |
| `股票行情: 查看自选股` | 浏览全部自选股行情 |
| `股票行情: 切换状态栏显示` | 显示/隐藏状态栏轮播 |
| `股票行情: 立即刷新` | 立即刷新一次行情 |

## 数据源

[腾讯实时行情接口](https://qt.gtimg.cn) —— 无需 API Key。

## 开发

```bash
npm install
npm run compile        # 或: npm run watch
# 在 VSCode 中按 F5 启动 Extension Development Host 调试
```

打包 `.vsix`：

```bash
npm run package
```
