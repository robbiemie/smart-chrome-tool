# 股票行情 (Stocks Ticker)

一个 VSCode 扩展，在命令面板查询**港股/美股**实时行情，配状态栏轮播与侧边栏自选股列表。

## 功能

- **命令面板查询**（`Cmd/Ctrl+Shift+P` → `股票行情: 查询`，或快捷键 `Cmd/Ctrl+Shift+S`）：
  输入港股代码（4-6位数字，如 `00700`）或美股代码（字母，如 `AAPL`），即时获取实时报价。
- **状态栏轮播**：在自选股之间轮播，显示现价 + 涨跌幅。
- **侧边栏自选股列表**（活动栏图标）：列出全部自选股及实时行情，行内按钮可移除。
- **价格提醒**：对自选股设置涨/跌目标价，支持**单次**（触发后自动停用，止盈/止损单）与**多次**（边沿触发，每次穿越阈值才提醒、不刷屏）两种模式。命中条件后右下角 toast 提示，带「查看」按钮可跳详情。侧边栏「价格提醒」视图可视化管理（编辑/启停/删除/清空）。
- **自适应刷新**：交易时段 5 秒，非交易时段 30 秒（港股/美股时段）。

## 命令

| 命令 | 说明 |
| --- | --- |
| `股票行情: 查询` | Quick Pick 搜索 + 实时报价 |
| `股票行情: 添加到自选股` | 通过输入框添加代码 |
| `股票行情: 从自选股移除` | 通过 Quick Pick / 侧边栏按钮移除 |
| `股票行情: 查看自选股` | 浏览全部自选股行情 |
| `股票行情: 切换状态栏显示` | 显示/隐藏状态栏轮播 |
| `股票行情: 立即刷新` | 立即刷新一次行情 |
| `股票行情: 设置价格提醒` | 引导式设置涨/跌目标价（单次/多次），可从自选股右键或提醒视图标题触发 |
| `股票行情: 编辑提醒` | 修改目标价 / 触发方向 / 模式（单次·多次），保存后重新装填并启用 |
| `股票行情: 启用/停用提醒` | 切换某条提醒的启用状态（停用后不再触发；重新启用会重新装填） |
| `股票行情: 删除提醒` | 删除单条提醒 |
| `股票行情: 清空价格提醒` | 清空全部提醒（需确认） |

## 价格提醒

- **触发条件**：`涨到` = 现价 ≥ 目标价；`跌到` = 现价 ≤ 目标价。
- **单次模式**：条件命中即弹 toast，随后自动停用（一次性止盈/止损单）。
- **多次模式**：边沿触发——只在条件由「未满足→满足」的瞬间弹一次，价格持续满足不重复弹；价格回落使条件再次不满足时自动重新装填，下次穿越再弹。
- **右下角 toast**：`🔴 ▲` 红涨 / `🟢 ▼` 绿跌（对齐状态栏 A 股配色），带「查看」按钮跳到状态栏详情。
- **编辑提醒**：列表行内「✏️」按钮或右键「编辑提醒」可修改目标价 / 方向 / 模式；保存即重新装填并启用，可用来复活已用完或已停用的提醒。股票本身不可改，需删除后重建。
- **侧边栏视图**：每条提醒展示方向、目标价、现价（条件满足时带 `✓`）、模式、状态（监听中 / 待回落 / 已停用 / 已用完）。图标对齐引擎行为：监听中显示方向箭头，待回落/已停用显示中性圆点。行内仅保留「编辑 / 删除」两个按钮，右键菜单另提供「启用/停用」。

## 数据源

[腾讯实时行情接口](https://qt.gtimg.cn) —— 无需 API Key。

## 开发

```bash
npm install
npm run compile        # 或: npm run watch
# 在 VSCode 中按 F5 启动 Extension Development Host 调试
```

打包 `.vsix`：

```bash
npm run package      # 打当前版本包，自动清理旧版本（保留最新一个）
npm run repackage    # 升一位 patch 版本并打一个新包，同时清理旧版本
```

每次打完新包，`release/` 中的旧版本 `.vsix` 会被自动移除，始终保留至少一个最新安装包。
